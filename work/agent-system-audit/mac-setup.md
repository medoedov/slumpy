# Выделенный Mac для Slumpy: покупка и настройка

> **Дата:** 2026-10-26.
> **Статус:** справочный файл. Он нужен при покупке и настройке Mac, а не при работе над агентской системой.
> **Связь с планом:** основной план лежит в `audit-and-plan.md`. Что агентской системе нужно от среды, описано там в разделе 11.5. Здесь только закупка и настройка машины.

## 1. Конфигурация Mac

| Вариант | Вердикт |
|---|---|
| 16/256 | Работает при регулярной чистке. Закончившееся место означает упавшие сборки, которые без владельца никто не починит |
| 16/512 | Рекомендую |
| 24/512 | Только при планах на параллельные сессии агента |
| 256 и внешний SSD | Внешний диск только для бэкапов |

**Расход диска:**

- Xcode и одна среда симулятора: около 30 ГБ;
- каждая дополнительная среда симулятора: около 9 ГБ;
- на реальном Mac с 256 ГБ папка разработчика доходила до 90 ГБ;
- система: 30–40 ГБ, это моя оценка;
- при обновлении Xcode временно нужно место ещё под одну его копию.

**M4 или M6.** В августе 2026 вышел Mac mini на M6, базовая версия 16/256 стоит $899. Для этой работы разница в процессоре несущественна. Берите ту модель с 512 ГБ, которая дешевле.

## 2. Организация выделенного Mac

1. **Режим сервера.** Mac не засыпает, сам включается после отключения питания, подключён к сети кабелем. FileVault включён. В macOS Tahoe после перезагрузки диск можно разблокировать по SSH.
2. **Отдельная учётная запись macOS** для разработки, без личных данных.
3. **Управление.**
   - Remote Control из браузера на Windows или из приложения Claude на телефоне.
   - Push-уведомления о вопросах и разрешениях.
   - Сессии в `tmux` или в режиме сервера, чтобы переживать разрывы связи.
   - Для редких действий в графическом интерфейсе удалённый экран через защищённый туннель, например Tailscale.
4. **Права Claude Code.** Задаются в репозитории, описаны в основном плане, раздел 11.5.
5. **Инструменты.**
   - Последняя стабильная Xcode.
   - Симуляторы iOS 18 и актуальной версии.
   - XcodeBuildMCP или скилл с командами.
   - Xcode MCP по желанию.
   - swift-format и SwiftLint.
   - Кеши сборки внутри папки проекта.
6. **iPhone.** Включить режим разработчика и сопрячь телефон с Mac по Wi-Fi. Как агент использует телефон, описано в основном плане, раздел 11.5.
7. **CI.** Xcode Cloud для проверки изменений перед слиянием в `dev` и для сборок TestFlight. В членство Apple Developer Program входит 25 часов в месяц. Подпись приложения Apple берёт на себя.
8. **Гигиена диска.** Еженедельный скрипт по расписанию плюс предупреждение при старте сессии.
9. **Воспроизводимость.** Скрипт настройки Mac лежит в репозитории.

## 3. Ручные действия владельца

Разово:

- покупка и включение Mac;
- вход в аккаунт Claude;
- Apple Developer Program;
- Apple ID в Xcode;
- сопряжение iPhone;
- заявка на Family Controls;
- ключ App Store Connect, хранится в Keychain или `.env`, в чат не пишется;
- доступ к GitHub.

Регулярно, по машине:

- разблокировка диска после редких перезагрузок.

Остальное участие владельца описано в основном плане, раздел 8.5.
