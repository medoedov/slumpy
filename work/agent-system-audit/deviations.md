> Строки называют, в чём отступление, и ссылаются на файл, где живёт действующее правило. Само правило здесь не пересказывается, чтобы запись не устаревала при его изменении.

## Что из независимой проверки не применено и почему

| Находка (`verification.md`) | Решение | Почему |
|---|---|---|
| §9 п. 1: защита `main` на GitHub | Отложено до сборок из `main` | `main` пока не используется. Для приватного репозитория правило защиты ветки требует платного тарифа GitHub (по документации GitHub, сверить при включении) |
| §9 п. 5: убрать запрет `git push * HEAD` и push без имени ветки, запретить `mcp__github__merge_pull_request` и `gh pr merge` | Оставлено как есть | Попытку убрать лишние запреты остановил фильтр безопасности: агент не ослабляет свои ограничения без явного разрешения владельца. Мешают они мало: агент указывает имя ветки явно. Запрет инструмента слияния целиком заблокировал бы и законные слияния в `dev`; решается вместе с защитой `main` |
| §7.4: хуки сейчас | Отложено до скелета | Хукам нужны реальные пути кода. Они работают и в облаке, поэтому делаются первыми сразу со скелетом |
| §9 п. 14: повторный замер на 15–30 USD | Не делаем | Многошаговый продуктовый случай и проверка ревьюера на T1 добавлены в пилот на Mac |
| §9 п. 10: правила кругов в одном файле | Разделены по ответственности | Основной агент не видит `reviewer.md`, поэтому действия вызывающего (лимит, лог, что делать по вердикту) живут в `core-process.md` (всегда загружен), определения вердиктов в `reviewer.md` |
| §2.3 п. 15: рабочие допущения записаны как решения | Не делаем | Допущения утверждены владельцем вместе с планом; при скелете они попадут в ADR |
| §2.5: строка об auto memory | Отложено до Mac | Auto memory живёт только на локальной машине |
| §1.2: исследование через встроенный Explore | Не делаем | Встроенный агент доступен без инструкции; отдельное правило его использование не меняет |
| §2.4: дубли «сборка только на Mac», Liquid Glass и запрет UI в пакете | Не делаем | Дубли не разошлись, а правило для Swift должно быть под рукой при правке кода. Разошедшиеся дубли исправлены |
