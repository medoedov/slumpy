# Slumpy

> **Этот README описывает проект на GitHub.** Общий вход для Claude Code и Codex —
> [AGENTS.md](AGENTS.md); подробные правила и знания находятся в `.claude/`.

## О проекте

**Slumpy — вечер с книгой вместо скролла.** Мобильное приложение для тех, кто хочет читать,
но вечер уходит в ленту. Запускаешь сессию чтения: кладёшь телефон экраном вниз, если читаешь
бумагу или Kindle, или читаешь с телефона, а соцсети в это время закрыты. Твой Slumpy —
персонаж с каменным лицом — радуется прочитанному за день. Друзья видят, что ты читаешь,
и вызывают тебя на дуэль.

Предполагаемый первый этап — MVP под iOS и закрытый тест через TestFlight. Продуктовое описание лежит
в [mvp.md](mvp.md).

## Структура проекта

```
AGENTS.md                   # Единый поддерживаемый вход для Claude Code и Codex
CLAUDE.md                   # Только @AGENTS.md для старых версий Claude Code
.claude/                    # Общая агентская система из трёх слоёв:
                            #   ядро, одинаковое для любых проектов: rules/core-*.md, агент-ревьюер, скиллы
                            #   пакет iOS: rules/platform.md и rules/swift.md
                            #   проект Slumpy: AGENTS.md и знания о проекте (skills/project-knowledge/references)
scripts/check               # Общая проверка: документы системы сейчас, сборка и тесты на Mac
scripts/check-*, test-checks  # Отдельные проверки и их самопроверка
.agents/skills/             # Короткие ссылки для Codex на три общих навыка
.githooks/                  # Старые Git hooks: заморожены и отключены
docs/decisions/             # Архитектурные решения (ADR)
docs/lessons.md             # Ловушки, на которые проект уже наступал
docs/tech-debt.md           # Технический долг: для агента, владельцу читать не нужно
mvp.md            # Черновик продуктового описания MVP (v0.3), положения — гипотезы
backlog.md        # Идеи фич и баги — что делать потом
work/             # Активные фичи и баги — что делаем сейчас
└── [feature]/    # spec.md (что делаем) и plan.md (как делаем, журнал)
```

Весь код приложения (SwiftUI, минимальная версия iOS — в ADR-0001) будет жить в этом репозитории и собираться на Mac.

## Методология разработки

Разработку ведёт AI-агент, владелец принимает продуктовые решения:

1. **Спецификация** — агент закрывает существенные продуктовые вопросы, до пяти в сообщении,
   и пишет `spec.md`;
2. **Реализация** — агент пишет технический бриф и код; рискованные изменения проверяет ревьюер;
3. **Финализация** — обновляем документацию проекта и переносим фичу в архив.

Идеи будущих фич и известные баги — в `backlog.md`. Текущая работа — в папке `work/`.

Одна задача — одна сессия агента: в новой сессии он не путается в старом контексте, а всё нужное
для продолжения лежит в `work/{feature}/`.

В обеих средах действуют одни правила. Claude Code использует свои настройки и Stop hook;
Codex получает те же правила через `AGENTS.md` и запускает общую проверку перед завершением.
Просроченное обслуживание системы выводится как напоминание и не мешает закончить текущую задачу.
Подробности подключения: [docs/agent-system.md](docs/agent-system.md#runtime-loading).
