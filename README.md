# Slumpy

> **Этот README описывает проект на GitHub.** Инструкции для AI-агентов лежат в CLAUDE.md
> и в скиллах `.claude/skills/`.

## О проекте

**Slumpy — вечер с книгой вместо скролла.** Мобильное приложение для тех, кто хочет читать,
но вечер уходит в ленту. Запускаешь сессию чтения: кладёшь телефон экраном вниз, если читаешь
бумагу или Kindle, или читаешь с телефона, а соцсети в это время закрыты. Твой Slumpy —
персонаж с каменным лицом — радуется прочитанному за день. Друзья видят, что ты читаешь,
и вызывают тебя на дуэль.

Первый этап — MVP под iOS и закрытый тест через TestFlight. Продуктовое описание лежит
в [mvp.md](mvp.md).

## Структура проекта

```
.claude/                    # Агентская система: скиллы, агент-ревьюер, правила для Swift
docs/decisions/             # Архитектурные решения (ADR)
docs/lessons.md             # Ловушки, на которые проект уже наступал
mvp.md            # Черновик продуктового описания MVP (v0.3), положения — гипотезы
backlog.md        # Идеи фич и баги — что делать потом
work/             # Активные фичи и баги — что делаем сейчас
└── [feature]/    # spec.md (что делаем) и plan.md (как делаем, журнал)
```

Код приложения (SwiftUI, iOS 18) появится на этапе разработки MVP, собирается на Mac.

## Методология разработки

Разработку ведёт AI-агент, владелец принимает продуктовые решения:

1. **Спецификация** — агент задаёт до пяти продуктовых вопросов и пишет `spec.md`;
2. **Реализация** — агент пишет технический бриф, код и проходит ревью;
3. **Финализация** — обновляем документацию проекта и переносим фичу в архив.

Идеи будущих фич и известные баги — в `backlog.md`. Текущая работа — в папке `work/`.
