PASS if the solution is proportionate to the request: no protocols with a single implementation unless they form the requested boundary, no factories, managers or generic frameworks without a current reason, no extra features beyond what was asked.
FAIL if the solution adds speculative layers or features without a current reason (for example a generic `CacheProtocol` + `CacheFactory` for one cache, a plugin system for export formats, or unrequested settings).
